# Market Compass

롯데웰푸드 관점의 식품 수출 기회를 탐색하는 개인 학습 프로젝트입니다.
확정 기획은 [project.md](project.md)를 따릅니다. 기업 내부 데이터는 없습니다.

현재 구현 범위는 **스위트 비스킷(HS 190531)의 정량 데이터 수집·계산**입니다.
소비자료 탐색, LLM, 제품별 HS 판정, 규제 검토, 추천 순위와 웹 화면은 아직 구현하지 않았습니다.
기본 표본국(호주·일본·미국)은 연결 검증용이며 추천 국가 TOP 3가 아닙니다.

## 실행

Python 3.12 기준, 저장소 루트(`/workspace/food_market`)에서 실행합니다.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m market_compass --reporters 36 392 842 --start-year 2022 --end-year 2024
.venv/bin/python -m unittest discover -s tests -v
```

결과는 `reports/quantitative.json`, 실제 원본 응답은 `data/raw/`에 저장됩니다.
두 경로 모두 Git에서 제외됩니다. 같은 조건의 재실행은 기존 응답과 원래 수집 시점을 재사용합니다.
최신 응답이 필요할 때만 `--refresh`를 붙이세요. 실패 시 종료 코드는 1이며, 새 보고서를 쓰지 않습니다.
기존 보고서가 있다면 이전 실행의 결과이므로 `generated_at`을 확인하세요.

## API 키와 비밀정보

현재 Comtrade 공개 미리보기 API는 키 없이 호출하며 **`.env`를 읽지 않습니다**.
OpenAI·검색 기능 구현 전에 다음처럼 직접 복사할 수 있습니다. 기존 `.env`는 덮어쓰지 마세요.

```bash
cp -n .env.example .env
chmod 600 .env
```

실제 키는 `.env`에만 입력하세요. `.env.example`은 항상 빈 값으로 유지합니다.
`.env`와 변형 파일은 `.gitignore`에서 제외합니다. `git add -f`로 강제로 추가하지 마세요.
Git 제외는 암호화가 아니므로 키를 채팅·화면 캡처·로그·보고서에 복사하지 마세요.
나중에 SDK 연결 시 키 로딩과 로그 비노출을 별도로 검증합니다.

## 수집 조건과 해석

- 공식 출처: `https://comtradeapi.un.org/public/v1/preview/C/A/HS`
- HS 조회 결과가 모두 H6(HS 2022)인지 검사하고 다른 버전이 섞이면 중단합니다.
  버전을 API 경로에 H6로 지정한 시험에서는 0건이 반환돼 분석에 사용하지 않았습니다.
  국가별 원래 분류와 환산 여부는 향후 추가 확인이 필요합니다.
- 연간 상품 수입, 세계 전체 상대국, 전체 운송·통관 조건, HS 190531을 조회합니다.
- 공식 HS 정의: “Food preparations; sweet biscuits, whether or not containing cocoa”.
- 롯데웰푸드 비스킷 목록에 있는 모든 제품이 이 코드에 속한다는 뜻은 아닙니다.
- 한 요청에 한 연도, 최대 5개 국가로 범위를 제한합니다. 500건 도달·중복·조건 불일치는 분석을 중단합니다.
- 연도 간 요청 간격은 최소 2초이며 429와 일부 일시 오류만 제한적으로 재시도합니다.
- `primaryValue`를 명목 USD 수입액으로 사용하고 `netWgt`는 kg로 보관합니다.
- 전년 대비 성장률 = `(당해 / 전년 - 1) × 100`.
- CAGR = `((마지막 / 첫해) ** (1 / 경과 연수) - 1) × 100`.
- 결측을 0으로 채우지 않습니다. 연속 연도가 모두 있어야 CAGR을 계산하고 기준값이 0이면 계산을 보류합니다.
- 전체 응답이 0건이면 실패로 종료합니다. 일부만 확보되면 보고서 상태는 `incomplete`입니다.
- 원본의 `isReported`, `isAggregate`, `isNetWgtEstimated`와 출처·수집 시점을 남깁니다.
- 집계된 수치가 자동으로 오류라는 뜻은 아닙니다. 국가 통계와 대조하기 전 결과는 모두 검토 대상으로 표시합니다.

수입시장 규모는 기업 매출·브랜드 판매량·실제 소비량과 다릅니다. 현재 결과만으로 추천하지 않습니다.

## 데이터 타당성 점검 결과 (2026-11-05)

- Comtrade 공식 HS 참조표와 키 없는 실제 응답 접근을 확인했습니다.
- 공개 미리보기는 한 요청에 한 연도만 허용하고 429 제한이 관찰됐습니다.
- 일본 응답의 수입액·중량은 별도 출처와의 대조가 필요합니다. 임의 수정하지 않습니다.
- [롯데웰푸드 비스킷 목록](https://www.lottewellfood.com/brand/product?searchType1=LC300) 접근을 확인했습니다.
- KOTRA 검색과 실제 기사 본문 접근을 확인했습니다. 중국 비스킷 기사(pNttSn=196680)의
  수입통계 기준은 190590이며 본 모듈의 190531 수치와 합치지 않습니다.
- 해당 중국 기사는 공공누리 제4유형입니다. 자동 추출·공개 재사용 가능 범위를 확인하거나 적합한 다른 자료를 선정해야 합니다.
- KATI는 검증 당시 HTTP 503으로 접근하지 못했습니다.

향후 단계에서는 정량 후보와 소비자료 후보를 별도로 탐색한 뒤 합치고, 기회 매력도와 진입 부담을 구분합니다.
근거가 부족하면 분석을 보류하며 TOP 3를 강제로 채우지 않습니다.
