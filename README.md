# Market Compass

롯데웰푸드 관점의 식품 수출 기회를 탐색하는 개인 학습 프로젝트입니다.
확정 기획은 [기획서 v1.0](docs/Market-Compass-기획서-v1.0.md)과 이후 승인사항을 따릅니다. 기업 내부 데이터는 없습니다.

현재 구현 범위는 **정량 데이터 수집·계산 + 고정 2개국 공개자료 비교 화면·로컬 SQLite 저장**입니다.
React + Vite 화면과 FastAPI 서버를 연결했습니다. 소비 근거·제품 연결 가설은 사전 작성된 시험 자료입니다.
자동 소비자료 탐색, LLM, 제품별 HS 판정, 규제 적합성 판정, 추천 순위는 아직 구현하지 않았습니다.
기본 표본국(호주·일본·미국)은 연결 검증용이며 추천 국가 TOP 3가 아닙니다.

## 로컬 비교 화면 실행

Python 3.12, Node.js 24 기준입니다. 최초 설치와 화면 빌드:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
npm --prefix web ci
npm --prefix web run build
.venv/bin/python -m uvicorn market_compass.api:app --host 127.0.0.1 --port 8000
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. API 키와 외부 DB 계정은 필요하지 않습니다.
화면의 ‘비교 실행 · 로컬 저장’을 누르면 공개 시험 자료의 통계를 기존 함수로 재계산하고,
제품 버전·소비 근거·연결 가설·미확인 사항을 함께 SQLite에 저장합니다.
저장된 실행은 왼쪽 목록에서 다시 열 수 있습니다. 자동 국가 발굴·실시간 통계 갱신·AI 분석은 수행하지 않습니다.

DB 기본 경로는 `data/market_compass.sqlite3`입니다. 별도 경로가 필요하면 서버의
`MARKET_COMPASS_DB` 환경변수로 지정합니다. `.env`를 자동으로 읽지는 않습니다.
SQLite 파일·원문 캐시·생성 보고서·`node_modules`·화면 빌드는 Git에서 제외됩니다.
소스에 포함된 `market_compass/fixtures/first_comparison.json`은 확인한 공개 통계 발췌와
공개 제품·소비 근거만 담은 시험 입력입니다. 기업자료를 이 파일에 넣지 마세요.
실제 기업자료 업로드 기능은 없고 로컬 자료를 외부 AI API로 전송하지 않습니다.

이 서버는 로그인 없는 개인용 로컬 시험입니다. `127.0.0.1` 바인딩을 유지하세요.
공개 배포·권한 설계·외부 DB 연결은 이번 구현에 포함하지 않았습니다.

화면 개발 시에는 두 터미널에서 API 서버와 `npm --prefix web run dev`를 실행합니다.
화면은 `http://127.0.0.1:5173`, `/api` 요청은 Vite가 로컬 FastAPI로 전달합니다.
빌드 화면을 쓰는 서버는 `web/dist`만 공개하고 저장소·DB·`.env`를 정적 파일로 제공하지 않습니다.

이번 환경에서는 스레드 기반 API 테스트가 샌드박스에서 대기해 제한 밖에서 실행했습니다.

개인 학습 프로토타입이며 롯데의 공식 서비스나 브랜드 승인을 받은 결과물이 아닙니다.

```bash

```

결과는 `reports/quantitative.json`, 실제 원본 응답은 `data/raw/`에 저장됩니다.
두 경로 모두 Git에서 제외됩니다. 같은 조건의 재실행은 기존 응답과 원래 수집 시점을 재사용합니다.
최신 응답이 필요할 때만 `--refresh`를 붙이세요. 실패 시 종료 코드는 1이며, 새 보고서를 쓰지 않습니다.
기존 보고서가 있다면 이전 실행의 결과이므로 `generated_at`을 확인하세요.

## API 키와 비밀정보

Comtrade 및 로컬 비교 화면은 키 없이 작동하며 **`.env`를 읽지 않습니다**.
OpenAI·검색 기능 구현 전에 다음처럼 직접 복사할 수 있습니다. 기존 `.env`는 덮어쓰지 마세요.

```bash
cp -n .env.example .env
chmod 600 .env
```

실제 키는 `.env`에만 입력하세요. `.env.example`은 항상 빈 값으로 유지합니다.
`.env`와 변형 파일은 `.gitignore`에서 제외합니다. `git add -f`로 강제로 추가하지 마세요.
Git 제외는 암호화가 아니므로 키를 채팅·화면 캡처·로그·보고서에 복사하지 마세요.
근거 추출 CLI만 저장소 루트의 `.env`에서 `OPENAI_API_KEY` 한 항목을 읽습니다.
환경변수에 이미 설정된 키가 있으면 그것을 우선합니다. `.env`의 셸 명령·변수 치환은 실행하지 않습니다.

## OpenAI 공개자료 1건 추출 시험

웹 서버와 별도 명령입니다. 모델은 `gpt-4.1-mini`, 공개 ABS 발췌는 393자,
출력 상한은 800토큰입니다. 추가 SDK 설치 없이 Python 표준 HTTP와 Pydantic을 사용합니다.
Function Calling으로 국가·품목 범위·신호·원문 인용·한계를 반환하게 하고 로컬에서 검증합니다.
통계 검색·제품 추천·웹 화면 갱신을 자동 수행하는 에이전트는 아직 아닙니다.

1. 설치한 가상환경을 활성화하고 `python -m pip install -r requirements.txt`를 실행합니다.
2. `.env.example`을 `.env`로 복사합니다. 기존 `.env`가 있으면 복사하지 않고 필요한 항목만 편집합니다.
3. 로컬 편집기에서 `OPENAI_API_KEY=` 뒤에 실제 키를 입력하고 저장합니다. 키를 터미널 명령이나 채팅에 붙이지 않습니다.
4. 먼저 무료 미리보기를 실행합니다:

```bash
python -m market_compass.extract
```

`mode: preview`, `network_calls: 0`을 확인한 다음 실제 요청을 허용하려면:

```bash
python -m market_compass.extract --execute
```

실제 호출은 사용자가 직접 실행합니다. `--execute`는 유료 요청 1회를 허용하며 자동 재시도는 없습니다.
입력은 `market_compass/fixtures/abs_excerpt.json`의 공개 원문 발췌·출처뿐입니다.
기업자료·API 키·제품 파일을 모델 입력으로 보내지 않습니다. 결과는 Git 제외된
`reports/extraction/<요청 해시>/result.json`에 출처·추출값·토큰 사용량과 함께 저장합니다.
로컬 SQLite와 웹 화면에는 이 단계의 결과를 자동 반영하지 않습니다.

검증 전 모델 응답도 `received.json`에 보관합니다. 저장 대상은 공개 원문·모델 출력·사용량뿐이며
인증 헤더나 HTTP 오류 본문은 저장하지 않습니다. 검증 실패 시 길이 제한·도구 호출·필드 형식·인용 불일치를 구분합니다.
아래 명령은 키를 읽거나 API를 호출하지 않고 보관된 응답만 재검증합니다:

```bash
python -m market_compass.extract --recheck
```

재검증을 통과하면 `result.json`을 저장하고 기존 실패 이력을 보존하며 완료 상태로 복구합니다.
웹·SQLite에는 자동 반영하지 않습니다. `stop` 종료라도 정상 도구 호출 1건·스키마·원문 인용·사용량이
검증되면 허용하며 잘린 응답·거절·빈 호출·잘못된 인용은 거부합니다. 모델 출력 내용 자체를 자동 교정하지 않습니다.
`received.json`을 저장하지 않았던 이전 버전의 실패 응답은 사용량 기록만으로 복원할 수 없습니다.
진단 코드만 바뀌었고 유료 요청 내용은 바꾸지 않았으므로 기존 중복 호출 방지 기록도 그대로 적용됩니다.

같은 입력으로 다시 실행하면 성공한 결과를 재사용해 요청을 보내지 않습니다.
실패·중단 시에도 `attempt.json`을 남겨 같은 입력의 자동 재호출을 막습니다.
타임아웃·잘못된 응답·저장 실패라도 과금됐을 수 있으므로 이 파일을 지워 바로 재시도하지 말고
플랫폼 사용 내역부터 확인하세요. 가능한 경우 실패 응답의 토큰 사용량도 기록합니다.
실패 본문·인증 헤더·비밀값은 출력하거나 저장하지 않습니다.

달러 단위 비용은 기록된 모델·토큰 사용량을 공식 요금표 및 플랫폼 청구 내역과 대조해야 합니다.
잔액을 자동 조회하지 않으며 $0.50 이하의 누적 지출을 프로그램이 보장하지 않습니다.
원문 인용이 일치해도 해석 정확성을 보장하지 않으므로 결과는 `needs_human_review`로 저장합니다.
실제 계정에서 모델 사용이 가능한지·실제 API 응답이 올바른지는 사용자 실행으로 확인할 사항입니다.

## 수집 조건과 해석

- 공식 출처: `https://comtradeapi.un.org/public/v1/preview/C/A/HS`
- HS 조회 결과가 모두 H6(HS 2022)인지 검사하고 다른 버전이 섞이면 중단합니다.
  버전을 API 경로에 H6로 지정한 시험에서는 0건이 반환돼 분석에 사용하지 않았습니다.
  국가별 원래 분류와 환산 여부는 향후 추가 확인이 필요합니다.
- 연간 상품 수입, 세계 전체 상대국, 전체 운송·통관 조건, HS 190531을 조회합니다.
- 공식 HS 정의: “Food preparations; sweet biscuits, whether or not containing cocoa”.
- 롯데웰푸드 비스킷 목록에 있는 모든 제품이 이 코드에 속한다는 뜻은 아닙니다.
- 한 요청에 한 연도, 최대 5개 국가로 범위를 제한합니다. 500건 도달·중복·조건 불일치는 분석을 중단합니다.
- 연도 간 요청 간격은 최소 2초이며 429와 일부 일시 오류만 제한적으로 재시도합니다.
- `primaryValue`를 명목 USD 수입액으로 사용하고 `netWgt`는 kg로 보관합니다.
- 전년 대비 성장률 = `(당해 / 전년 - 1) × 100`.
- CAGR = `((마지막 / 첫해) ** (1 / 경과 연수) - 1) × 100`.
- 결측을 0으로 채우지 않습니다. 연속 연도가 모두 있어야 CAGR을 계산하고 기준값이 0이면 계산을 보류합니다.
- 전체 응답이 0건이면 실패로 종료합니다. 일부만 확보되면 보고서 상태는 `incomplete`입니다.
- 원본의 `isReported`, `isAggregate`, `isNetWgtEstimated`와 출처·수집 시점을 남깁니다.
- 집계된 수치가 자동으로 오류라는 뜻은 아닙니다. 국가 통계와 대조하기 전 결과는 모두 검토 대상으로 표시합니다.

수입시장 규모는 기업 매출·브랜드 판매량·실제 소비량과 다릅니다. 현재 결과만으로 추천하지 않습니다.
