# 첫 구현 전 점검: 기존 코드와 비교 입력

점검일: 2026-11-09. 사용자 요청 범위는 기존 테스트 재실행 및 첫 비교 국가·기간 선정이다.
애플리케이션 코드·의존성·프레임워크·DB·환경 설정은 변경하지 않았다.

## 1. 기존 코드 검증

실행: `.venv/bin/python -m unittest discover -s tests -v`

결과: **16개 테스트 통과**.

- 성장률·결측·기준값 0·중복·조건 불일치·비정상 수치 처리.
- 캐시 재사용·캐시 손상·재시도·API 오류·잘림 의심 응답 처리.
- 전체 0건일 때 실패하고 기존 보고서를 덮어쓰지 않는 처리.

이 테스트의 API 관련 검증은 모의 응답을 사용한다. 현재 외부 API 접속·쿼터·실제 데이터 정확성까지 검증한 것은 아니다.
따라서 보관된 실제 응답을 기존 분석 함수에 넣어 별도 확인했다.

## 2. 첫 입력 선택

| 항목 | 선택 |
|---|---|
| 제품 | P01 빠다코코낫 오리지널, P01-public-label-v1 |
| 국가 | 호주 36, 일본 392 |
| 통계 기간 | 2022~2024년, 공통 연속 3개년 |
| 조회 범위 | HS190531, H6, 연간 상품 수입, 상대국 세계 전체, 전체 운송·통관 조건 |
| 용도 | 정량 계산·출처·소비 근거·미확인을 연결하는 고정 국가 시험 |
| 최종 국가 순위 | 산정하지 않음 |

두 국가는 확보된 통계 원본과 소비·산업·규제 근거를 재사용할 수 있어 선택했다.
호주는 소매 판매 기반 소비 추정자료, 일본은 업계 추계 및 통관 범위 차이를 가진 사례다.
일본은 비교가 쉬운 정상 시장 사례가 아니라 **제품 범위 차이를 표시하는 검증 사례**로 포함한다.
독립 후보 발굴이 구현됐거나 이 국가가 최선의 수출국이라는 뜻은 아니다.
인도·몽골은 기존 소비 경로·제품 매칭 시험 사례로 유지하며 폐기하거나 기회가 낮다고 처리하지 않는다.

기간 선택 이유:

- 기본 목표는 최근 비교 가능한 5개년이지만 확보한 2021 응답은 H5이며 이후 H6와 연속성이 미확정이다.
- 2022~2024는 기존 코드의 출처·수집시점 포함 캐시에 공통 3개년이 모두 있다.
- 2025 조사 응답도 있으나 기존 수집 캐시와 보관 형식이 달라 이번에는 재현 가능한 최소 입력으로 3개년을 사용한다.
- 이는 가장 최신 기간의 우선순위 분석이 아니라 첫 기술 연결 시험을 위한 선택이다. 2025를 결측이나 사용 불가로 처리하지 않는다.

## 3. 실제 캐시 재계산 결과

2026-11-05 수집 원본 3개에서 호주·일본 행만 선택했다. 원본에 함께 들어 있던 미국 행은 이번 계산에서 제외했다.
원본은 수정하지 않았으며 6개 국가×연도 행의 조건·누락·중복을 기존 코드로 검사했다.

| 연도 | 호주 수입액, 명목 USD | 일본 수입액, 명목 USD |
|---|---:|---:|
| 2022 | 176,012,576.281 | 95,316.934 |
| 2023 | 171,034,882.609 | 165,488.062 |
| 2024 | 214,618,000.014 | 163,722.035 |

기간 내 계산값: 호주 CAGR 약 10.42%, 일본 약 31.06%.
이는 해당 API 계열의 산술 결과이며 두 국가의 비스킷 전체 성장성·매력도 순위가 아니다.
누락 없는 6행을 확보했다는 의미의 complete와 제품 범위 비교 가능성·추천 가능성은 별개다.
두 국가 모두 기존 함수의 `requires_review=true`를 유지한다.

일본 업계의 스위트·가당 비스킷 수입 범위에는 190531000 외에 190590312가 포함된다.
따라서 위 일본 수입액을 일본 비스킷 전체 시장 규모로 사용하거나
호주보다 작으므로 기회가 적다고 판단하지 않는다. 전체 시장 우열 비교는 보류한다.
두 국가 모두 `isReported=false`, `isAggregate=true` 등 원래 응답 상태와 출처를 결과에 보존했다.

출력 파일: `reports/preflight/quantitative-au-jp-2022-2024.json`.
출처 URL·원래 수집시점·입력 파일 경로·SHA-256·연도별 값·요약·비교 한계를 담았다.
기존 `reports/quantitative.json`은 덮어쓰지 않았다. 생성물은 기존 Git 제외 경로에 있다.

## 4. 함께 사용할 소비·시장 근거

이번 단계에서는 새 국가 조사를 늘리지 않고 기존에 읽고 보관한 원문을 재사용한다.

| 국가 | 연결할 자료 | 표시할 사실 | 주장하지 않을 것 |
|---|---|---|---|
| 호주 | ABS apparent consumption, 2024~25 회계연도, 2026-10-30 발표 | 소매 판매 기반 스위트 비스킷 추정치 13.9→13.6g/인/일, 본문 전년 대비 2.2% 감소 | 실제 섭취량·코코넛 선호·P01 판매량 |
| 일본 | 전국비스킷협회 2025 생산·소매 추계 및 수입표 | 비스킷류 산업 규모 자료가 있고 수입 합산 범위가 HS190531 단독과 다름 | 생산량=소비량, 넓은 시장통계=P01 수요 |

호주 자료는 회계연도이며 Comtrade 달력연도와 합치거나 공통 시간축의 동일 지표로 취급하지 않는다.
일본 자료는 소비자 선호 조사가 아닌 산업 추계로 표시한다.
P01의 원재료·규격 등은 제품 카드와 연결하며 소비자료에서 미확인 제품 속성을 생성하지 않는다.
두 국가의 결과는 제품별 구매 근거·가격·주요 수입 조건이 미확인임을 함께 출력해야 한다.

주요 출처:

- ABS: https://www.abs.gov.au/statistics/health/food-and-nutrition/apparent-consumption-selected-foodstuffs-australia/latest-release
- 일본 협회: https://www.biscuit.or.jp/biscuit_data.html
- 일본 생산표: https://www.biscuit.or.jp/img/documents/about/012_statistics_2026.xlsx
- 일본 수입표: https://www.biscuit.or.jp/img/documents/about/022_import_export_data_2026.xlsx
- 원문·접근 한계: [기존 호주·일본 조사](research/2026-11-09-biscuit-feasibility.md).
- 제품 근거: [P01 공개 제품 카드](product-p01-evidence.md).

ABS의 latest-release는 나중에 변경될 수 있다. 첫 시험에는 보관된 2024~25 자료 버전을 사용하고
새로 수집할 때 기준 기간을 다시 확인한다.

## 5. 확인한 구현 차이와 다음 작업

기존 분석 함수는 최소 2개 연도를 허용하지만 기획서의 최소 성장 추세 기간은 3개 연도다.
이번 실행은 3개 연도를 명시해 기획 조건을 충족했고 코드를 수정하지 않았다.
이 차이는 다음 구현 시 다룰 항목이다. 이번 테스트 통과를 기획 전체 구현 완료로 해석하지 않는다.

다음은 이 입력·결과의 화면/API 연결에 맞는 기술 구성을 비교하는 단계다.
국가별 시장 순위, 새 자료 수집기, LLM 매칭·웹·DB는 이번 점검에서 개발하지 않았다.
