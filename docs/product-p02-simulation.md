## A02: 가상 투입 배합

**굽기 전 반죽 투입 총중량 100g 기준**이다. 물을 포함하며 각 비율 합계는 100%다.
굽는 동안 수분이 빠지므로 완제품 100g당 원료 함량이나 포장 표시용 함량으로 전용하지 않는다.
완제품 수율·잔존 수분·원료 규격·실제 제조 가능성은 미검증이다.

| 원료 | 투입량 | 투입 중량 비율 |
|---|---:|---:|
| 밀가루 | 37g | 37% |
| 귀리가루 | 20g | 20% |
| 건조 코코넛 분말(가당하지 않은 원료 가정) | 7g | 7% |
| 설탕 | 16g | 16% |
| 카놀라유 | 10g | 10% |
| 버터 | 3g | 3% |
| 물 | 6g | 6% |
| 소금 | 0.5g | 0.5% |
| 탄산수소나트륨 | 0.5g | 0.5% |
| 합계 | 100g | 100% |

이는 제품 특성·알레르기·첨가물 검토 항목을 표현하기 위한 시험 배합이다.
실제 원료의 세부 조성·첨가물·교차접촉 정보는 공급사 규격서가 있어야 확인할 수 있다.
탄산수소나트륨 등 첨가물의 용도·허용 기준도 실제 대상국 자료로 검토해야 한다.

## A03: 가상 영양 입력값

아래는 **완제품 100g 기준으로 별도 설정한 가상값**이다.
원료 영양 DB·굽기 수율이 없어 A02로부터 산출한 영양 추정값이라고 주장하지 않는다.
1봉 기준은 100g 값에 0.3을 곱한 계산값이다. 법정 라벨의 반올림 규칙은 적용하지 않았다.

| 항목 | 가상값: 완제품 100g당 | 계산값: 1봉 30g당 |
|---|---:|---:|
| 열량 | 486kcal | 145.8kcal |
| 탄수화물 | 65g | 19.5g |
| 당류 | 21g | 6.3g |
| 지방 | 22g | 6.6g |
| 포화지방 | 8g | 2.4g |
| 단백질 | 7g | 2.1g |
| 나트륨 | 420mg | 126mg |
| 트랜스지방 | 미설정 | 미설정 |
| 콜레스테롤 | 미설정 | 미설정 |
| 식이섬유 | 미설정 | 미설정 |

미설정은 0이 아니다. 버터를 넣고도 동물성 원료가 없다고 판단하거나,
귀리를 넣었다는 이유만으로 식이섬유 함량을 생성하지 않는다.
저당·고식이섬유·비건·글루텐프리·건강 개선 표현은 부여하지 않는다.

검증한 산술 관계:

- 투입 배합 합계 100g = 100%.
- 포장 중량 30g × 4봉 = 120g. 가정한 개당 중량 3g × 10개 = 30g.
- 단순 4/9/4 열량 점검: 65×4 + 22×9 + 7×4 = 486kcal.
- 당류 21g ≤ 탄수화물 65g, 포화지방 8g ≤ 지방 22g.
- 탄수화물·지방·단백질 합계 94g ≤ 100g. 남은 6g을 검증된 수분량으로 해석하지 않음.

위 검증은 시험 데이터의 산술 일관성만 확인한다. 배합과 영양값의 실제 일치,
생산 가능성·보관 안정성·영양 표시 적합성을 검증한 것은 아니다.

## A05: 기한 가정의 적용 범위

9개월은 보관·운송 조사에서 확인할 질문을 구체화하기 위한 목표값이다.
안정성 시험을 거친 소비기한이나 품질유지기한으로 표시하지 않는다.
실제 기한 유형·기산 방식·조건은 대상국 기준과 제품 시험으로 정해야 한다.
15~25°C 조건을 썼다는 이유만으로 냉장 불필요·상온 장거리 운송 적합·열대국 진출 가능을 확정하지 않는다.

어느 국가가 어느 제품을 선호할지와 TOP 3는 미리 만들지 않는다.
