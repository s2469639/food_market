# 첫 로컬 작동 버전

구현 기준일: 2026-11-09. 기획서 v1.0 이후 사용자가 로컬 저장과 구현 착수를 승인했다.

## 범위

- React + Vite / TypeScript 화면 → FastAPI → 기존 pandas 계산 → 로컬 SQLite 저장.
- P01 빠다코코낫, 호주·일본, 2022~2024년 시험 입력만 사용한다.
- 공개자료 발췌를 저장소의 명시적 시험 입력으로 보관해 새 체크아웃에서도 외부 API 없이 재현한다.
- 실행할 때 정량 지표를 재계산한다. 소비 신호·연결 가설은 기존 조사에서 사람이 작성한 내용이다.
- 실행 ID·저장 시각·제품 버전·사용한 출처와 원본 해시·계산 결과·미확인을 함께 저장한다.
- 실행 이력을 불러올 때 새 자료로 덮지 않고 당시 JSON 스냅샷을 복원한다.
- 일본의 HS 통계 범위 차이를 표시하고 국가 간 시장 순위는 만들지 않는다.
- 자료 부족 화면은 필요한 자료·확보처·해소 조건·확인 범위를 보여준다.

저장은 완료된 비교 결과 단위다. 긴 조사의 단계별 중간 저장·실패 후 자동 재개는 아직 없다.
계산·자료 검증에 실패하면 실행을 성공으로 저장하지 않는다. 저장 오류는 사용자에게 표시한다.

## 미구현

자동 후보 발굴·검색·현지어 플랫폼 연동·에이전트·제품별 HS 판정·실제 규제 적합성 검증·추천 TOP 3는 미구현이다.
로그인·기업자료 업로드·외부 DB·외부 AI API도 연결하지 않았다.
P02는 기존 가상 제품 문서에 남아 있으며 이번 첫 화면의 선택 대상으로 추가하지 않았다.

## 디자인

사용자 공유 이미지의 롯데 레드 `#DA291C`, 회색, 흰 바탕을 활용한다.
붉은색은 실행 버튼·현재 선택 등 제한된 강조에 사용한다.
사용자가 제공한 https://uxdev.org/blog/108-10-2019/ 에서 설명하는 정보 위계·그룹핑·명확한 레이블을 참고했다.
큰 홍보 문구·장식성 그래프 대신 제품과 실행 조건, 비교 근거, 추가 확인을 중심으로 배치했다.
공식 로고·상품 사진·타 서비스 화면을 복제하지 않았다.

## 검증 결과

- 기존 16개 + 추가 4개 = 20개 Python 테스트 통과.
- TypeScript 검사 및 Vite production build 통과.
- 실제 Chromium: 실행/저장, 연도별 값·출처 펼치기, 추가 확인, 새로고침 후 이력 복원,
  390px 모바일 가로 넘침 없음, 저장 오류 표시, JavaScript 예외 없음 확인.
- `.env`·SQLite·저장소 파일 요청은 404이며 빌드 폴더만 정적 제공한다.
- DB 파일 및 빌드·의존성 폴더의 Git 제외 확인.
- DB는 해당 클라우드 작업 환경의 로컬 파일이다. 사용자 PC로 자동 복사하거나 Git에 저장하지 않는다.

서버 실행·개발 방법은 README를 따른다. 게시·배포·커밋·푸시는 하지 않았다.
