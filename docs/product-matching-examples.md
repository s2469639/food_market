# 제품 매칭 결과 카드: 기획 검증 예시

작성일: 2026-11-09. 기존 조사 근거를 재사용한 문서 예시다. 추가 국가 조사·코드 구현은 하지 않았다.
인도와 몽골은 동작을 확인할 사례이며 추천 순위·국가 평가 결과가 아니다.
두 카드의 ‘추가 검증 유망’은 표시 방식을 시험하는 상태 예시로, 최종 추천 자격 심사를 완료했다는 뜻이 아니다.
P02는 사용자가 허용한 가상 제품 초안에 대한 조건부 매칭이다.

## 카드 1 — 인도 × 빠다코코낫

**기회 가설: 현지에 공급되는 코코넛 쿠키와 비교해 볼 수 있는 버터·코코넛 비스킷**

표시 상태 예시: **추가 검증 유망**. 코코넛 쿠키 공급과 간편 포장 관련 신호가 있어 후보로 유지한다.

| 구분 | 카드 내용 |
|---|---|
| 제품 속성 — 실제 확인 | P01-public-label-v1. 공식 소개에 버터·코코넛을 사용한 달콤한 비스킷. 공개 표시 기준 100g, 50g × 2봉 [P1] |
| 소비·시장 신호 — 출처 확인 | Britannia 공식 제품군에 코코넛 쿠키가 있고 연결된 판매처에 100g 상품이 제시된다 [I1,I2]. KOTRA는 이동 중 간식 및 개별 포장 쿠키·비스킷을 언급한다 [I3] |
| 제품 적합성 — 연결 가설 | 코코넛 풍미와 봉지 포장이라는 접점으로 현지 상품과 비교 검토할 수 있다. 실제 소비자의 P01 선택 가능성은 아직 가설이다 |
| 공통점과 차별성 | 코코넛은 경쟁제품과 공통된 특성이므로 시장 연결 단서다. P01만의 차별성으로 표시하지 않는다. 검증된 선택 우위는 아직 없다 |
| 반대 근거·부담 | 현지 코코넛 쿠키가 이미 존재하며 기존 브랜드·저가 팩 경쟁도 강하다 [I1,I4] |
| 중요한 미확인 | P01의 현지 판매 여부, 비교 시 선호·가격 수용성, 주요 진입 제약. 신규 진출인지 제품군 확대인지도 미확인 |
| 후속 확인 질문 | 기존 코코넛 쿠키와 비교했을 때 P01을 선택할 구체적 이유가 있는가? |

**이 자료로 말할 수 있는 것:** 제품 비교를 시작할 풍미·포장 접점과 경쟁 대상이 있다.

**아직 뒷받침하지 못하는 것:** P01의 실제 구매 수요, 경쟁제품보다 높은 선호·판매량, 유리한 가격, 수출 적합성.

## 카드 2 — 몽골 × 가상 귀리·코코넛 미니 비스킷

**가상 제품 시뮬레이션 / 기회 가설: 소포장 간식 흐름과 30g 봉지 구성의 연결**

표시 상태 예시: **추가 검증 유망 — 가상 제품 조건부**.
관련 간접 신호가 있어 후보를 유지하고, 현지어 근거 확보 실패를 기회 부족으로 해석하지 않는다.

| 구분 | 카드 내용 |
|---|---|
| 제품 속성 — 가상 입력 | P02-simulation-v1-draft. 귀리·코코넛 미니 비스킷, 약 3g × 10개를 담은 30g 봉지 4개. 실제 롯데 제품·분석 성적이 아니다 [P2] |
| 소비·시장 신호 — 출처 확인 | KOTRA는 휴대성·보관 편의성을 갖춘 소포장 과자 수요와 편의점의 소용량 간식 판매를 서술한다 [M1]. 소비자 직접 설문으로 확인한 것은 아니다 |
| 제품 적합성 — 연결 가설 | 30g 봉지는 휴대하거나 나눠 먹는 간식 상황과 연결해 검토할 수 있다. 미니 크기·귀리·코코넛 조합의 선호는 별도 가설이다 |
| 공통점과 차별성 | 소포장은 시장에서 쓰이는 형식과의 접점이다. P02만의 우위나 ‘현지에서 없는 제품’으로 표현하지 않는다 |
| 반대 근거·부담 | 보고서는 인접국 제품과의 가격 경쟁을 서술한다 [M1]. 4봉 묶음은 총 구매금액이 있어 소액 단품 구매 수요와 동일하게 볼 수 없다 |
| 중요한 미확인 | 풍미·귀리·미니 크기의 소비 반응, 묶음 구성과 가격 수용성, 주요 진입 제약. 현지 판매처 원문 보강도 미완료 |
| 후속 확인 질문 | 30g 봉지를 여러 번 나눠 먹는 구성에 연결되는 근거가 있는가? 단품 구매와 묶음 구매를 구분할 필요가 있는가? |

**이 자료로 말할 수 있는 것:** 작은 봉지 구성과 관련된 조사 가설을 유지할 이유가 있다.

**아직 뒷받침하지 못하는 것:** 귀리·코코넛 선호, 건강식 적합성, P02 구매 수요·수출 가능성, 낮은 총 구매가격.

P02 가상 제품이라는 점은 매칭 시험을 중단할 이유가 아니다. 입력 속성의 가정임을 유지하고
실제 시장 근거와 연결하는 설명이 타당한지를 시험한다. 저당·비건 등 입력에 없는 속성은 추가하지 않는다.

## 이번 예시에서 확인할 세 가지

| 기획 질문 | 예시에 반영한 방식 |
|---|---|
| 간접 신호에서도 후보가 유지되는가? | 두 카드 모두 직접 구매 실적 없이 조사 가설을 유지하고 근거의 범위를 표시 |
| 공통 특징을 차별성으로 과장하지 않는가? | 코코넛·소포장을 시장 접점으로 사용하고 독점적 우위·높은 선호로 해석하지 않음 |
| 정보 부족을 탈락과 구분하는가? | 미확인 항목과 다음 질문을 남김. 자료 수·현지어 검색 실패로 국가 탈락 처리하지 않음 |

이 표는 문서 예시가 해당 구분을 표현하는지 확인한 것이다. 자동화 성능·실사용자 이해도·실제 구매 가능성을 검증한 결과가 아니다.
국가별 추가 자료를 끝까지 모으는 대신 이 두 사례로 카드 구성이 이해되는지 검토한다.
새로운 배점·수치 신뢰도·복잡한 검증 절차는 추가하지 않는다.

탐색 후보 유지·제품 매칭 가설 작성·최종 추천 자격은 다른 판단이다.
최종 추천의 소비 근거 충분성을 어디까지 인정할지는 후속 결정이며,
직접 구매·판매 또는 소비조사 자료가 없다는 이유만으로 탐색·매칭 후보를 자동 탈락시키지 않는다.
결론을 바꿀 자료 충돌이나 중대한 규제 미확인은 그 판단을 보류할 수 있다.
