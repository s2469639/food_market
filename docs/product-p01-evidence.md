## 영양정보: 표시값과 환산값

S3의 영양표 기준은 **1봉(50g)**이다. 공통 카드의 100g 기준은 표시값을 2배 환산했다.
100g당 열량 494kcal는 포장 앞면 표시와도 일치한다.

| 영양 항목 | 표시값: 50g당 | 계산값: 100g당 |
|---|---:|---:|
| 열량 | 247kcal | 494kcal |
| 탄수화물 | 34g | 68g |
| 당류 | 12g | 24g |
| 지방 | 11g | 22g |
| 포화지방 | 6.6g | 13.2g |
| 트랜스지방 | 0g | 0g |
| 단백질 | 3g | 6g |
| 나트륨 | 160mg | 320mg |
| 콜레스테롤 | 0mg | 0mg |

출처의 반올림된 표시값을 환산한 수치이며 별도 실험 분석값이 아니다.
0 표시는 해당 라벨의 표시값으로 보존하고 물질의 절대적 부재를 뜻한다고 해석하지 않는다.
식이섬유 등 보이지 않는 항목은 0으로 채우지 않는다.

검증: 50g당 탄수화물·단백질 4kcal/g, 지방 9kcal/g으로 단순 대조하면
34×4 + 3×4 + 11×9 = 247kcal로 표시 열량과 일치한다.
당류 ≤ 탄수화물, 포화지방 ≤ 지방의 포함 관계도 모순이 없다.
이는 전사·단위 확인이며 영양표의 법적 적합성 검증은 아니다.

## 이번 조사로 가능한 일과 남은 확인

- 이 버전의 제품 특성을 바탕으로 버터·코코넛 비스킷의 소비 근거 탐색을 시작할 수 있다.
- 50g × 2봉은 P02의 1회분 포장 가정과 비교할 때 참고할 수 있지만, 포장 형태만으로 휴대성 선호나 구매 수요를 확정하지 않는다.
- 제품의 수출 적합성이나 최종 추천에 적용하기 전에는 대상 생산분·내수/수출 규격·최신 라벨을 확인해야 한다.
- 전체 원재료·복합원료·첨가물 전사 및 국가별 규제 대조는 아직 완료하지 않았다.
- 소비기한의 총 개월 수와 수출 운송 조건은 미확인으로 유지한다. 가상 제품의 6~12개월 가정을 P01에 넣지 않는다.

검색 결과에는 다른 맛 제품과 서로 다른 열량 수치가 나타났지만, 원문 규격을 대조하지 못한 수치는 채택하지 않았다.
블로그·AI 요약·검색 미리보기는 이 카드의 영양 수치 근거로 사용하지 않았다.
