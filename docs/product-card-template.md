# 프로토타입 공통 제품 카드

목적: 기존 제품 1개와 진출 검토 신제품 1개를 같은 구조로 입력하고 근거·가정을 구분한다.
기획용 양식이며 코드·DB 스키마 구현은 아니다. 빈칸은 실제 데이터가 없다는 뜻이며 0으로 채우지 않는다.

설명만으로 상세 배합·HS 코드·수출용 규격·기간을 확정하지 않는다.

P01의 규격별 확인값·영양 환산·출처·최신성 한계는 [실제 제품 조사 카드](product-p01-evidence.md)에 기록했다.
조사 기준 버전은 P01-public-label-v1이며 실제 확인값과 계산값을 구분한다.

P02는 사용자가 선택한 독립적인 가상 신제품 콘셉트이며 실제 롯데 출시 제품이 아니다.
출퇴근·업무 중 간식은 검토할 섭취 상황 가설이다. 포장·배합·영양·기한 가정은
[가상 제품 카드](product-p02-simulation.md)에 P02-simulation-v1-draft로 작성했다. 구체 수치는 검토용 초안이다.
귀리 등의 원료만으로 저당·고식이섬유·비건을 주장하지 않는다.
P01과 원료·식감·크기·포장·섭취 상황에 따른 기회 차이를 검토하되,
P01의 비교 속성은 출처로 확인하고 어느 국가가 P02를 선호할지는 실제 소비자료로 조사한다.

## 공통 입력 항목

| 묶음 | 입력 항목 | 기록 원칙 |
|---|---|---|
| 식별 | 제품 ID·버전·이름·제품 단계·제품군·규격 | 제품의 기존/신제품 구분과 실제/가상 구분을 별도로 기록 |
| 제품 특성 | 맛·식감·원료·섭취 상황·소비층 가설 | 사실과 기획 가정 구분. 제품 특성에서 현지 수요를 역으로 만들어내지 않음 |
| 원재료·배합 | 원료명·복합원료 구성·중량 비율(알면) | 실제 비공개 배합을 추정해 사실로 채우지 않음. 완전한 가상 배합표는 비율 합계·기준 명시 |
| 알레르기 | 함유·교차접촉 정보 | 근거 없는 ‘없음’ 금지. 국가별 표시 항목과 별도 대조 |

| 포장 | 순중량·개수·개별포장·포장 방식 | 내수·수출 규격과 배합 기준을 혼동하지 않음 |

| 보관·운송 | 온도·습도·차광 등 조건 | 기한과 조건을 연결하고 모르면 미확인. 제품군만으로 일괄 확정하지 않음 |
| 생산·공급 | 제조국·제조 주체·수출용/내수용 등 | 실제 확인값과 가상 시나리오를 구분 |
| 통계 연결 | 국가별 후보 HS·버전·설명·확인 상태 | 마케팅상 제품군 이름만으로 통관 분류 확정 금지 |

영양 수치는 보관기간만으로 만들 수 없다. 시험용 수치를 구성하는 경우에도
배합·당류/탄수화물 등의 포함 관계·단위와 모순되지 않는지 확인하고 실제 분석값으로 제시하지 않는다.
단순 배합 계산은 실제 영양검사나 보관 안정성 검증을 대체하지 않는다.

## 모든 항목에 붙일 근거 정보

| 값 | 상태 | 출처 또는 가정 ID | 기준일/확인일 | 적용 제품 버전·규격 | 비고 |
|---|---|---|---|---|---|
| 미입력 | 실제 확인 / 가상 시험값 / 미확인 중 선택 | 원문 URL·라벨·규격서 또는 가정 설명 | 미입력 | 미입력 | 미입력 |

실제 P01의 빈 정보를 가상값으로 덮지 않는다. 필요하면 P01에서 파생된 가상 카드 버전을 별도로 만든다.
P02도 실제 확인한 시장 자료와 가상 제품 속성의 경계를 유지한다.

## 분석 결과 연결

- 제품 카드와 버전을 고정해 국가별 기회·출처·판정에 연결한다.
- 현지어 검색에는 두 제품의 공통점과 차이점을 사용할 수 있지만 제품 선호를 미리 가정하지 않는다.
- 기존/신제품은 제품 단계이고, 신규 진출/제품군 확대/진출 현황 확인 필요는 국가별 기회 유형이다.
- 기한·영양 등의 시험 가정으로 확인한 것은 조건부 시뮬레이션이며 실제 제품의 추천·허가 검증이 아니다.
- 현 제품의 기회, 제품 자체의 조정이 필요한 가설, 핵심 정보 부족으로 보류한 판단을 구분한다.

## 다음에 정할 항목

1. P01은 공개 100g 표시 기준으로 초기 탐색 가능. 최종 판단에 필요한 최신 대상 생산분·수출 규격·총 소비기한 확인은 남음.
2. P02 초안의 포장·배합·영양 시험값·기한 가정을 묶어서 검토한다.
3. 검토한 제품 특성으로 작은 규모의 실제 소비자료 조사를 진행할 범위를 정한다.

P01은 공개 자료 조사로 일부 실제 값을 확보했고 P02는 가상 수치 초안을 작성했다. 코드 개발·자료 수집 API 구현은 이번 작업에 포함하지 않았다.
